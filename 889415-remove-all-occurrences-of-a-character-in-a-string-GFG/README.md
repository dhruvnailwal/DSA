# [Remove all occurrences of a character in a string](https://www.geeksforgeeks.org/problems/remove-all-occurrences-of-a-character-in-a-string/1)
## Easy
Given a string s and a character c. The task is to remove all the occurrences of the character in the string.
Examples:
Input:&nbsp;s = "geeksforgeeks", c = 'e'Output: s = "gksforgks"
Input: s = "geeksforgeeks", c = 'g'Output: s = "eeksforeeks"
Constraints:1 &lt;= |s| &lt;= 105
